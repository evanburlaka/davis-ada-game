# Davis-ADA-Game
## City of Davis educational games — ADA accessibility compliance project (CSC 131, Fall 2025)
This game teaches about the dangers of Stormwater Pollution and how to prevent it, It includes two Mini-games; Find it and Fix it and Protect or Pollute
